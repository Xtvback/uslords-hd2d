# USLORDS — O Despertar dos Colares

Protótipo gratuito de RPG isométrico no navegador, inspirado no universo original USLORDS.

## Jogar
Abra `index.html` num navegador moderno. Para disponibilizar online, ative GitHub Pages em Settings > Pages > Deploy from a branch > main / root.

## Controlos
WASD/setas: mover; Shift: correr; Espaço: detonação; E: conversar; M: estado.

## Direção artística
Objetivo: personagens animadas em pixel art HD-2D e cidade de Speranzu isométrica com profundidade. A versão inicial é um protótipo técnico, não gráficos finais.

Personagens: TNT (cabeça caixa TNT, hoodie vermelho, sempre calçado), Aeris (vestido lilás e flor) e Mask (máscara preta, descalço).
